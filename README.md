# 📚 Used Book Management System

A web application for managing used books, developed using Flask and SQLite. This project was created to practice full-stack web development, including CRUD operations, database management, and web application deployment.

---

## ✨ Features

- 📖 View all books
- ➕ Add a new book
- ✏️ Edit book information
- ❌ Delete books
- 🔍 Search books
- 💾 Store data in SQLite
- 🌐 Simple and user-friendly web interface

---

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ttuyetttt98/ngttuyetproject.git
```

### 2. Move into the project directory

```bash
cd ngttuyetproject
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

macOS / Linux

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Then open your browser and visit

```
http://127.0.0.1:5000
```
